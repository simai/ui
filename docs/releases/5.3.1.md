# SIMAI UI Core 5.3.1

Дата релиза: 2026-07-11

## Что исправлено

SFLoader теперь дедуплицирует конкурентные запросы одного и того же JS/CSS
asset по итоговому versioned URL. Это устраняет повторные `script` и `link`,
которые появлялись при первичной отрисовке сложных smart-компонентов, включая
`sf-table`.

Внутренние карты хранят promise незавершённой или успешной загрузки. При
network error запись удаляется, поэтому явная повторная попытка остаётся
возможной.

## Изменённые файлы

- `distr/core/js/core-loader.js`
- `distr/core/js/core-loader.js.gz`

## Проверено

- конкурентные relation-цепочки `sf-table`;
- один `script[src]` и `link[href]` на итоговый URL;
- локальные pinned paths без CDN;
- совместимость с `simai/ui-smart` `v5.3.0`.

## Установка

```html
<script>
  window.sfPath = 'https://cdn.jsdelivr.net/gh/simai/ui@v5.3.1/distr';
  window.sfSmartPath = 'https://cdn.jsdelivr.net/gh/simai/ui-smart@v5.3.0';
</script>
<script src="https://cdn.jsdelivr.net/gh/simai/ui@v5.3.1/distr/core/js/core.js"></script>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/simai/ui@v5.3.1/distr/core/css/core.css">
```
