# SIMAI UI Core 5.6.0

Дата релиза: 2026-09-02

Совместимый minor-релиз обновляет обычный Accordion: делает его семантически
доступным, предсказуемым в нескольких сценариях и единообразным с поверхностями
SIMAI Framework.

## Добавлено

- Независимое раскрытие разделов и режим одного открытого раздела
  `data-sf-accordion-mode="single"`.
- Контурный `sf-accordion--outline` и встроенный
  `sf-accordion--flush` варианты наряду со стандартной заполненной
  поверхностью.
- Публичные token hooks для радиуса, границы, разделителя и внутренних
  отступов без абсолютных проектных размеров.

## Изменено

- Интерактивным владельцем состояния стала нативная
  `.sf-accordion-trigger`; панель получает устойчивую ARIA-связь.
- Шеврон использует одну модель вправо → вниз, включая корректное начальное
  направление в RTL.
- Разделитель не появляется только на hover и не меняет геометрию компонента.
- Заголовок и содержимое используют один базовый размер текста; иерархию задаёт
  начертание.

## Совместимость

- Существующая разметка Accordion остаётся рабочей через legacy-адаптер.
- Публичные пути, Loader API, `sfPath`, необязательный `sfSmartPath`,
  `core.css` и `core.js` не менялись.
- Совместимая Smart-поставка: `simai/ui-smart` `v5.4.0`.
