# SIMAI UI Core 5.6.2

Patch-релиз исправляет Admin Menu и связанный Context Menu, сохраняя полный
публичный состав Framework.

## Что изменилось

- Admin Menu больше не выглядит обрезанным в контейнере без заданной высоты:
  внутренняя прокрутка включается только при реальном ограничении пространства.
- Навигационные группы, активный пункт, клавиатурный focus и RTL-поведение
  приведены к единому контракту Framework.
- Context Menu корректно работает как меню действий внутри Admin Menu.
- Loader сохраняет обнаружение `file-preview` и `link` из закреплённого
  compatibility-контура.

## Совместимость

Публичные классы, пути ресурсов и Loader API не изменены. Используйте
`simai/ui-smart` `v5.4.1` для совместимого Smart runtime.
