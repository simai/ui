# SIMAI UI Core 5.1.0

Дата релиза: 2026-06-11

## Версия

`5.1.0`

Схема версионирования: `major.minor.patch`.

- `major = 5` - линия SIMAI Framework 5.
- `minor = 1` - добавлены новые smart/component assets и расширен utility/runtime слой.
- `patch = 0` - первый minor-релиз после `5.0.0`.

## Что изменилось по сравнению с 5.0.0

### Добавлено

- Добавлены собранные компоненты `admin-menu`, `datepicker`, `tree`, `tree-item`.
- Обновлены smart-component metadata и runtime assets: `distr/smart-component-meta.json`, `distr/core/js/smart-base.js`, `distr/core/js/core-loader.js`, `distr/core/js/core-rules.js`.
- Добавлены новые JS chunks core runtime: `distr/core/js/358.js`, `distr/core/js/438.js`, `distr/core/js/904.js`.
- Обновлены данные для редакторских подсказок и переменных: `distr/monaco-css-vars.json`.

### Изменено

- Обновлены собранные CSS/JS обычных компонентов: buttons, checkbox, context-menu, dropdown, inputs, modal, pagination, range-slider, slider, tabs, tags и другие.
- Расширены utility-модули: `flex`, `align-content`, `headers`, `transform-translate`, `transform-translate-ext`, `transition-property`.
- Обновлены core CSS bundle и полный utility bundle: `distr/core/css/core.css`, `distr/core/css/utility.full.css`.
- Обновлены правила загрузчика: `distr/rule/rule.json`, `distr/rule/js/rule.js`.

## Собранные файлы

Дистрибутив находится в каталоге `distr/`.

Основные директории:

- `distr/core/` - базовый runtime, loader, core CSS и smart runtime assets.
- `distr/component/` - обычные UI-компоненты и component assets, включая компоненты, используемые smart-слоем.
- `distr/utility/` - utility CSS/JS модули.
- `distr/rule/` - правила загрузчика.
- `distr/fonts/` - шрифты и font assets.
- `distr/source/` - служебные source/meta assets.

Состав релиза `5.1.0`:

- всего файлов: `2583`;
- CSS-файлов: `711`;
- JS-файлов: `939`;
- gzip-артефактов: `630`;
- JSON-файлов: `18`;
- общий размер: около `39.34 MB`.

## Установка через CDN

```html
<script>
  window.sfPath = 'https://cdn.jsdelivr.net/gh/simai/ui-core@v5.1.0/distr';
</script>

<script src="https://cdn.jsdelivr.net/gh/simai/ui-core@v5.1.0/distr/core/js/core.js"></script>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/simai/ui-core@v5.1.0/distr/core/css/core.css">
```

Если проект использует отдельный путь для smart-компонентов, можно явно указать `window.sfSmartPath`. Для текущего пакета он обычно совпадает с `window.sfPath`:

```html
<script>
  window.sfPath = 'https://cdn.jsdelivr.net/gh/simai/ui-core@v5.1.0/distr';
  window.sfSmartPath = 'https://cdn.jsdelivr.net/gh/simai/ui-core@v5.1.0/distr';
</script>
```

## Локальная установка

1. Скопировать каталог `distr/` в публичную директорию проекта.
2. Указать `window.sfPath` на корень скопированного дистрибутива.
3. Подключить core JS и core CSS.

```html
<script>
  window.sfPath = '/distr';
</script>

<script src="/distr/core/js/core.js"></script>
<link rel="stylesheet" href="/distr/core/css/core.css">
```

## Проверка после установки

Минимальная проверка:

1. Открыть страницу с подключенным core.
2. Убедиться, что в консоли нет ошибок загрузки `core.js`, `core.css`, `rule.json` и smart metadata.
3. Добавить в DOM обычный компонент, например `sf-button`.
4. Добавить smart-компонент, например `sf-datepicker` или `sf-tree`.
5. Проверить, что loader подгружает нужные assets из указанного `window.sfPath`.

Пример:

```html
<sf-button type="default" scheme="primary" text="Проверка"></sf-button>
<sf-datepicker locale="ru-RU"></sf-datepicker>
```
