# SIMAI UI Core 5.6.4

Patch-релиз восстанавливает полный контракт утилит между CSS и Loader.

## Что изменилось

- Добавлены однозначные канонические имена для выравнивания, промежутков,
  высоты по содержимому и изоляции; опубликованные имена SF5 сохранены как
  совместимые псевдонимы.
- Loader распознаёт весь публичный CSS-контракт из 28 058 классов и 640
  модулей, включая responsive-, state- и отрицательные формы.
- Исправлен порядок отрицательных модификаторов и исключена загрузка по
  совпадению с частью постороннего класса.
- Встроенный полный utility bundle и изолированные utility-модули собраны из
  одного source-коммита одним закреплённым builder-коммитом.

## Совместимость

`content-main-*`, старые формы gap и height остаются работоспособными в SF5.
Неоднозначный общий класс `auto` заменён на `isolation-auto`. Используйте
`simai/ui-smart` `v5.4.1` для совместимого Smart runtime.
