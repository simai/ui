# SIMAI UI Core 5.0.0

Дата релиза: 2026-05-13

## Версия

`5.0.0`

Схема версионирования: `major.minor.patch`.

- `major = 5` - линия SIMAI Framework 5.
- `minor = 0` - первый формальный релиз UI Core в этой линии.
- `patch = 0` - базовая релизная поставка без отдельного patch-номера.

## Что изменилось

Изменения в рамках подготовки релиза:

- зафиксирована версия `5.0.0`;
- подготовлено описание установки через CDN и локальный `distr/`;
- описан состав собранного дистрибутива;
- добавлен changelog для дальнейшего сравнения релизов;
- зафиксирована рекомендация использовать pinned tag вместо ветки `main`.
- добавлен CSS cascade layer `sf.utilities` для utility-стилей. Теперь utility CSS находится в общей системе слоев SF, а порядок переопределения между utilities, components и states управляется через cascade layers, а не случайным порядком подключения файлов.

Для следующего релиза изменения нужно считать от тега `v5.0.0`.


## Установка через CDN

```html
<script>
  window.sfPath = 'https://cdn.jsdelivr.net/gh/simai/ui-core@v5.0.0/distr';
</script>

<script src="https://cdn.jsdelivr.net/gh/simai/ui-core@v5.0.0/distr/core/js/core.js"></script>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/simai/ui-core@v5.0.0/distr/core/css/core.css">
```

Если проект использует отдельный путь для smart-компонентов:

```html
<script>
  window.sfPath = 'https://cdn.jsdelivr.net/gh/simai/ui-core@v5.0.0/distr';
  window.sfSmartPath = 'https://cdn.jsdelivr.net/gh/simai/ui-core@v5.0.0/distr';
</script>
```

## Локальная установка

1. Скопировать каталог `distr/` в публичную директорию проекта.
2. Указать `window.sfPath`.
3. Подключить core JS и core CSS.

```html
<script>
  window.sfPath = '/distr';
</script>

<script src="/distr/core/js/core.js"></script>
<link rel="stylesheet" href="/distr/core/css/core.css">
```

## Проверка после установки

Минимальная проверка:

1. Открыть страницу с подключенным core.
2. Убедиться, что в консоли нет ошибок загрузки `core.js` и `core.css`.
3. Добавить в DOM простой компонент, например `sf-button`.
4. Проверить, что loader подгружает нужные assets из указанного `window.sfPath`.

Пример:

```html
<sf-button type="default" scheme="primary" text="Проверка"></sf-button>
```

## Примечания для публикации

Перед публикацией релиза нужно:

1. Зафиксировать изменения commit-ом.
2. Создать git tag `v5.0.0`.
3. Запушить commit и tag.
4. Создать GitHub Release `v5.0.0`.
5. Приложить архив `ui-core-5.0.0.zip`, если релиз должен содержать скачиваемый artifact помимо содержимого репозитория.
