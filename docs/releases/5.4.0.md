# SIMAI UI Core 5.4.0

Дата релиза: 2026-08-28

Minor-релиз объединяет новую типографику, стабильную production-загрузку,
доступные контракты полей, Button Group и компактный загрузчик кандидата №2.

## Добавлено

- Необязательный Asset Planner первого кадра на основе существующего
  `distr/rule/rule.json`.
- Обычный Button Group и правила загрузки Smart Button Group.
- Единый доступный контракт Input и Textarea.
- Production handoff через `window.SF_PRELOADED` без изменения обычного
  динамического режима Loader.

## Изменено

- Типографика 5.4 использует метрически совместимый локальный fallback и
  `font-display: optional`, чтобы исключить поздний скачок каркаса.
- Highlight умеет сохранять заранее отрисованную оболочку блока кода.
- Menu и Icon резервируют итоговую геометрию до регистрации компонентов.
- Загрузчик использует компактный кандидат №2: `48px`, `1800ms`, размах
  `6px`, поворот `90°`, theme-safe цвет поверхности и статичный вариант для
  `prefers-reduced-motion`.

## Совместимость

- Сохраняются `sfPath`, необязательный `sfSmartPath`, `core.css` и `core.js`.
- Проекты без сборки продолжают работать через прежнее динамическое
  обнаружение ресурсов.
- Исторические runtime-пути сохранены через digest-bound compatibility corpus.
- Совместимая Smart-поставка: `simai/ui-smart` `v5.4.0`.

## Проверка

- Две независимые сборочные волны дали одинаковый manifest SHA для Core,
  Component, Utility и Smart.
- Source прошёл lint, 111 unit-тестов, проверку 43 Smart-контрактов и
  синхронизацию Studio artifacts.
