# SIMAI UI Core 5.4.1

Дата релиза: 2026-08-30

Patch-релиз добавляет нейтральный машинный контракт публичной поверхности
Framework для Docara и других документационных систем. Runtime API и привычное
подключение Framework не меняются.

## Добавлено

- Детерминированный `contracts/generated/documentation-source.json` со схемой
  `docara.documentation_source.v1`.
- Публичные классы, custom properties, зависимости, provenance и стабильные
  ключи Core, 226 utility-семейств, 63 компонентов, 43 Smart Components и
  source-owned recipes.
- Семантические зоны радиусов: `--sf-radius--ui` для компактных контролов и
  `--sf-radius-default` для крупных поверхностей.

## Исправлено

- Loader registry теперь включает существующие компоненты `file-preview` и
  `link`.
- Восстановлена byte-identical gzip-поставка десяти runtime-ресурсов,
  унаследованных от сборки `5.4.0`.

## Совместимость

- `sfPath`, необязательный `sfSmartPath`, `core.css`, `core.js` и динамический
  Loader работают без изменений.
- Контракт документации является необязательным generated artifact.
- Совместимая Smart-поставка остаётся `simai/ui-smart` `v5.4.0`.

## Проверка

- Registry: 333 source entities и отдельная core design-token entity.
- Framework registry suite: 30 тестов успешно, один внешний Larena lock test
  пропущен из-за отсутствия необязательной переменной окружения.
- Generated registry и documentation source воспроизводятся byte-identical.
