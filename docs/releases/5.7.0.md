# SIMAI UI Core 5.7.0

Minor-релиз закрепляет фундамент SIMAI Framework 5: имена Utility, адаптивную
систему размеров, точную маршрутизацию Loader и общую основу Smart Components.

## Что изменилось

- Канонические имена выравнивания, интервалов, высот и isolation получили
  единый контракт; опубликованные совместимые имена продолжают работать.
- Responsive, state и отрицательные формы используют однозначный порядок
  модификаторов.
- Loader и Production Asset Planner распознают только целые class-токены.
- Добавлены исполняемые контракты UI Heights, семантических интервалов,
  логических сторон, container queries и dimension policy.
- CSS ↔ Loader матрица проверяет 643 Utility rules и предотвращает повторное
  расхождение исходников, дистрибутива и документации.

## Проверка

Core, Component, Utility и Smart дважды собраны из точных source и builder
commit. Обе волны побайтово идентичны; 472 legacy-записи прошли проверку.

## Совместимость

Публичные пути ресурсов и совместимые aliases сохранены. Используйте
`simai/ui-smart` `v5.5.0`.
