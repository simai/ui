# SIMAI UI Core 5.3.2

Patch release removing the external Google Fonts runtime dependency from the
documentation component.

## Changed

- `distr/component/doc/css/doc.css` no longer imports
  `fonts.googleapis.com`.
- Code and source samples continue to use the bundled `--sf-mono` token.
- The matching gzip artifact is rebuilt deterministically.

## Compatibility

- Public paths and CSS selectors are unchanged.
- Compatible with `simai/ui-smart` `v5.3.0`.
