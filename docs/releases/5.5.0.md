# SIMAI UI Core 5.5.0

Дата релиза: 2026-09-01

Minor-релиз добавляет универсальную доставку подмножеств иконок без изменения
привычного подключения Framework. Production-сборка может подготовить только
нужные глифы, а Loader сохраняет поддержку позднего динамического содержимого.

## Добавлено

- Поддержка хешированных подмножеств `outlined`, `rounded` и `sharp`,
  создаваемых общим генератором `ui-builder`.
- Точные локальные fallback-шрифты для семейств `rounded` и `sharp`.
- Семейно-изолированные manifests и накопление иконок текущей сессии.

## Изменено

- Новый subset применяется только после успешной загрузки и проверки шрифта.
- Одновременные DOM-изменения объединяются в один запрос для каждого
  семейства.
- Кеш браузера и `localStorage` ускоряют повторную загрузку, но итоговая
  корректность определяется manifest и хешами.

## Исправлено

- Сетевой fallback `@latest` удалён.
- При ошибке сервиса Loader использует локальный полный шрифт и не оставляет
  вместо иконок текстовые ligatures.
- Повторные ошибки одного семейства не создают поток одинаковых сообщений в
  консоли.

## Совместимость

- `sfPath`, необязательный `sfSmartPath`, `core.css`, `core.js`, CSS-классы и
  HTML-разметка не изменены.
- Проекты без сборки продолжают использовать динамическое обнаружение Loader.
- `simai/ui-smart` `v5.4.0` остаётся совместимой Smart-поставкой.
- Исторические runtime-файлы проверены по 472 digest-bound записям из
  `v5.4.1`.
