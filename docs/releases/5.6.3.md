# SIMAI UI Core 5.6.3

Patch-релиз возвращает видимую иконку для уведомлений с ролью `success`.

## Что изменилось

- `sf-alert--success` задаёт иконке семантический цвет `--sf-success` вместо
  прозрачного значения.
- Обычный и минифицированный CSS, а также gzip-артефакты снова совпадают
  побайтово после распаковки.
- Добавлена регрессионная проверка роли цвета и сжатых артефактов Alerts.

## Совместимость

Публичная разметка, классы, Loader API и пути ресурсов не изменены. Используйте
`simai/ui-smart` `v5.4.1` для совместимого Smart runtime.
