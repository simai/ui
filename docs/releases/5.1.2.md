# SIMAI UI Core 5.1.2

Дата релиза: 2026-06-11

## Что изменилось

Исправлено правило загрузки smart-компонента таблицы `sf-table`.

В релизе `5.1.1` loader уже перестал автоматически запрашивать CSS для smart-компонентов без `css: true`, но у `cl-table` оставалась relation на обычный компонент `table`. Такого компонента в `ui-core` нет, поэтому браузер мог запрашивать несуществующий файл:

```text
distr/component/table/css/table.css
```

Теперь `cl-table` сам объявляет `css: true`, а ошибочная relation на `table` удалена. CSS таблицы должен грузиться из smart-слоя.

## Собранные файлы

Обновлены:

- `distr/rule/rule.json`
- `distr/rule/js/rule.js`
- `distr/rule/js/rule.js.gz`

## Установка

```html
<script>
  window.sfPath = 'https://cdn.jsdelivr.net/gh/simai/ui@v5.1.2/distr';
</script>

<script src="https://cdn.jsdelivr.net/gh/simai/ui@v5.1.2/distr/core/js/core.js"></script>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/simai/ui@v5.1.2/distr/core/css/core.css">
```

Для smart-компонентов используйте отдельный smart-дистрибутив:

```html
<script>
  window.sfSmartPath = 'https://cdn.jsdelivr.net/gh/simai/ui-smart@v5.1.0';
</script>
```
