# SIMAI UI Core 5.1.1

Дата релиза: 2026-06-11

## Версия

`5.1.1`

Схема версионирования: `major.minor.patch`.

- `major = 5` - линия SIMAI Framework 5.
- `minor = 1` - текущая minor-линия smart/component assets и utility/runtime слоя.
- `patch = 1` - bugfix loader после релиза `5.1.0`.

## Что изменилось по сравнению с 5.1.0

### Исправлено

- Исправлена загрузка CSS для smart-компонентов в standalone loader.
- Для `type: "smart"` и `mode: "smart"` CSS теперь не грузится по умолчанию.
- Smart CSS грузится только при явном `css: true` в rule/module metadata.
- Убрана причина лишних 404-запросов вида `/smart/<component>/css/<component>.css` и `/smart/<component>/css/<component>.min.css` для smart-компонентов, у которых стили находятся в обычном component layer.

### Затронутые файлы

- `distr/core/js/core-loader.js`
- `distr/core/js/core-loader.js.gz`

## Установка через CDN

```html
<script>
  window.sfPath = 'https://cdn.jsdelivr.net/gh/simai/ui@v5.1.1/distr';
</script>

<script src="https://cdn.jsdelivr.net/gh/simai/ui@v5.1.1/distr/core/js/core.js"></script>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/simai/ui@v5.1.1/distr/core/css/core.css">
```

Если проект использует отдельный путь для smart-компонентов:

```html
<script>
  window.sfPath = 'https://cdn.jsdelivr.net/gh/simai/ui@v5.1.1/distr';
  window.sfSmartPath = 'https://cdn.jsdelivr.net/gh/simai/ui-smart@v5.1.0';
</script>
```

## Проверка после установки

1. Очистить старый SF-кеш в браузере или поднять `pluginListVersion/cacheVersion` проекта.
2. Открыть страницу со smart-компонентами, например `sf-pagination`, `sf-badges`, `sf-icons`.
3. Проверить, что нет 404-запросов к `/smart/<component>/css/<component>.css` для smart-компонентов без `css: true`.
4. Проверить, что smart-компоненты с явным smart CSS продолжают загружать CSS.
